# presorted-set-intersection-algorithm2
This repository implements an algorithm to compute the intersection of two sets (elements included in both sets). This implementation uses a presorted approach, which leverages Merge Sort before searching for intersected elements. It also uses integer sets (represented as arrays), but the data type may be changed. There are global fields that may be adjusted to demonstrate the intersections of different sets. These fields allow you to adjust how the sets are randomized, including adjusting the maximum number of elements in the sets (duplicates are removed) and the range of integers the sets may have. Additionally, there are commented-out lines of code in main() that allow you to specify the sets' elements if you do not want randomized sets.
